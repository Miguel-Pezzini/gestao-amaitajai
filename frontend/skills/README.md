# Frontend Skills

Este diretório mapeia as skills de frontend disponíveis no projeto.

## Ordem recomendada de leitura

1. `frontend/skills/frontend-componentization/SKILL.md`

## Quando usar

- `frontend-componentization`
  - Criar ou refatorar páginas React.
  - Reduzir arquivos grandes.
  - Separar composição de UI, lógica em hooks e utilitários.

## Documentação de módulo

Antes de alterar uma feature, ler `docs/modules/<modulo>.md` (ver índice em `docs/modules/README.md`).

Após mudanças funcionais, atualizar o mesmo arquivo com novas telas, fluxos ou validações de UI.

## Regra operacional

Em qualquer tarefa de frontend, o agente deve:

1. Ler a documentação do módulo em `docs/modules/`.
2. Ler este README e a skill mapeada.
3. Atualizar `docs/modules/<modulo>.md` ao finalizar alterações funcionais.
