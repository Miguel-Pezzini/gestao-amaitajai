# Frontend Skills

Este diretório mapeia as skills de frontend disponíveis no projeto.

## Ordem recomendada de leitura

1. `frontend/skills/frontend-componentization/SKILL.md`

## Quando usar

- `frontend-componentization`
  - Criar ou refatorar páginas React.
  - Reduzir arquivos grandes.
  - Separar composição de UI, lógica em hooks e utilitários.

## Regra operacional

Em qualquer tarefa de frontend, o agente deve ler este README e a skill mapeada antes de começar alterações.
